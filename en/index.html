03

Where the figures come from

  1. 01
    The summary is written

    The system runs in an environment separate from this site and writes a sanitised summary to a public read-only store about every 10 minutes.

  2. 02
    One direction only

    The private side writes that one file outward. There is no path from the public side back into the private side. The write key exists only on the trading server and is valid for that single file.

  3. 03
    This page only renders it

    The site holds no credentials and never connects to the trading server. If the site were compromised, the page itself is the only thing that could be altered.

The summary contains no account number, no balance, no open positions or entry prices, no pending orders, no stop or target levels, and no model parameters. What the page can show is everything it can obtain.

04

Operating rules

Stated scope

XAUUSD (gold) only at present. If instruments are added later, this page is updated first — the scope is never widened quietly.

Stop loss on every order

An order without a stop is never sent. Risk per trade is fixed before the order leaves.

Fixed size

Every order is the same fixed minimum size; no martingale doubling. At most 3 positions are open at once, and a position that reaches its stop is closed.

Loss cut-off

After the daily loss limit is reached no new position is opened that day; below the equity floor the system stops opening positions.

Funds stay separate

Copying and fee settlement are performed by the broker's systems. Neither this site nor the provider handles investor funds.

Read-only by construction

A static page with no connection to the trading server: no login, no order entry, no payments.
